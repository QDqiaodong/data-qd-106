# 公告站协议

输入是调用方控制的本地模拟站目录，入口 index.html。不是某个真实监管站适配器。
HTML 的 a[rel=next] 遍历列表页，a[rel=notice] 指向详情；循环链接只读一次。
详情脚本 type=application/json，字段 recall_id/published/product/lots/reason 严格匹配。
日期为 ISO 日，lots 为非空字符串数组，排序去重；其余文本原样保存。
同一 recall_id 的内容必须一致，不支持修订。跨页面重复不重复入库。
recalls 表保存召回/产品/批号/原因；sources 表保存源站相对文件路径，可查来源。
只接受根目录内 HTML，拒绝外链、查询串、片段和越界路径（包括符号链接越界），单页上限1MB。
源站应只放公开或合成文件，本站 fixture 全为合成。最多1000页，全量读入后事务入库。
存在内容冲突时整批数据回滚；已有数据保留。失败时新建空库/表可能存在。
不发起网络请求，不涉及真实接口或第三方使用条件。数据库重复采集 inserted=0。

根内符号链接及根内绝对文件路径允许，来源路径按解析后的规范文件位置记录；
同一文件的多个别名只解析一次。交付fixture只使用相对链接，不含绝对路径或符号链接。
